# ViewRecycler Core

`ViewRecycler` is the framework-neutral package for data sources, layouts,
virtualization policy, diagnostics, and compatible ItemView reuse. It is for
adapter authors and advanced consumers that need Core primitives directly;
React products should normally start with `ViewRecyclerReact`.
